# PSStarr

PSStarr is a PowerShell 7 client module for Radarr, Sonarr, and Prowlarr.

It provides typed commands for application configuration, common API operations, and reusable automation.

## Supported applications

| Application | API version |
| --- | --- |
| Radarr | v3 |
| Sonarr | v3 |
| Prowlarr | v1 |

## Install

```powershell
Install-Module -Name PSStarr -Repository PSGallery
```
