# Get-StarrQueue

## SYNOPSIS

Retrieves queue records from a Starr instance.

## SYNTAX

### Named (Default)

```
Get-StarrQueue [-InstanceName <string>] [-Application <string>] [-Page <int>] [-PageSize <int>]
 [-SortKey <string>] [-SortDirection <string>] [-IncludeUnknownMovieItems <bool>]
 [-IncludeMovie <bool>] [-MovieIdFilter <int[]>] [-IncludeUnknownSeriesItems <bool>]
 [-IncludeSeries <bool>] [-IncludeEpisode <bool>] [-SeriesIdFilter <int[]>] [-Protocol <string>]
 [-LanguageIdFilter <int[]>] [-QualityIdFilter <int[]>] [-Status <string[]>]
```

### Explicit

```
Get-StarrQueue -Url <string> -ApiKey <string> [-Application <string>] [-Page <int>]
 [-PageSize <int>] [-SortKey <string>] [-SortDirection <string>] [-IncludeUnknownMovieItems <bool>]
 [-IncludeMovie <bool>] [-MovieIdFilter <int[]>] [-IncludeUnknownSeriesItems <bool>]
 [-IncludeSeries <bool>] [-IncludeEpisode <bool>] [-SeriesIdFilter <int[]>] [-Protocol <string>]
 [-LanguageIdFilter <int[]>] [-QualityIdFilter <int[]>] [-Status <string[]>]
```

## DESCRIPTION

This function retrieves download-queue records.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-StarrQueue
```

### EXAMPLE 2

```powershell
Get-StarrQueue -InstanceName 'Main'
```

### EXAMPLE 3

```powershell
'
```
