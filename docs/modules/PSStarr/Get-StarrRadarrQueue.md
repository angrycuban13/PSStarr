# Get-StarrRadarrQueue

## SYNOPSIS

Retrieves the Radarr download queue.

## SYNTAX

### Named (Default)

```
Get-StarrRadarrQueue [-InstanceName <string>] [-Page <int>] [-PageSize <int>] [-SortKey <string>]
 [-SortDirection <string>] [-IncludeUnknownMovieItems <bool>] [-IncludeMovie <bool>]
 [-MovieIdFilter <int[]>] [-Protocol <string>] [-LanguageIdFilter <int[]>]
 [-QualityIdFilter <int[]>] [-Status <string[]>]
```

### Explicit

```
Get-StarrRadarrQueue -Url <string> -ApiKey <string> [-Page <int>] [-PageSize <int>]
 [-SortKey <string>] [-SortDirection <string>] [-IncludeUnknownMovieItems <bool>]
 [-IncludeMovie <bool>] [-MovieIdFilter <int[]>] [-Protocol <string>] [-LanguageIdFilter <int[]>]
 [-QualityIdFilter <int[]>] [-Status <string[]>]
```

## DESCRIPTION

This function retrieves paged Radarr queue records.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-StarrRadarrQueue -InstanceName RadarrMain
```

### EXAMPLE 2

```powershell
Get-StarrRadarrQueue -InstanceName RadarrMain -MovieIdFilter 42,43 -IncludeMovie $true
```
