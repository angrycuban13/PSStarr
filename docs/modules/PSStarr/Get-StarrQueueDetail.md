# Get-StarrQueueDetail

## SYNOPSIS

Retrieves queue details from a Starr instance.

## SYNTAX

### Named (Default)

```
Get-StarrQueueDetail [-InstanceName <string>] [-Application <string>] [-MovieId <int>]
 [-IncludeMovie <bool>] [-SeriesId <int>] [-EpisodeIdFilter <int[]>] [-IncludeSeries <bool>]
 [-IncludeEpisode <bool>]
```

### Explicit

```
Get-StarrQueueDetail -Url <string> -ApiKey <string> [-Application <string>] [-MovieId <int>]
 [-IncludeMovie <bool>] [-SeriesId <int>] [-EpisodeIdFilter <int[]>] [-IncludeSeries <bool>]
 [-IncludeEpisode <bool>]
```

## DESCRIPTION

This function retrieves detailed download-queue records.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-StarrQueueDetail
```

### EXAMPLE 2

```powershell
Get-StarrQueueDetail -InstanceName 'Main'
```

### EXAMPLE 3

```powershell
'
```
