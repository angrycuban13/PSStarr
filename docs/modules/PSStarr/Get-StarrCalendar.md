# Get-StarrCalendar

## SYNOPSIS

Retrieves calendar records from a Starr instance.

## SYNTAX

### Named (Default)

```
Get-StarrCalendar [-InstanceName <string>] [-Application <string>] [-Start <datetime>]
 [-End <datetime>] [-Unmonitored <bool>] [-Tags <string>] [-TagIdFilter <int[]>]
 [-IncludeSeries <bool>] [-IncludeEpisodeFile <bool>] [-IncludeEpisodeImages <bool>]
```

### Explicit

```
Get-StarrCalendar -Url <string> -ApiKey <string> [-Application <string>] [-Start <datetime>]
 [-End <datetime>] [-Unmonitored <bool>] [-Tags <string>] [-TagIdFilter <int[]>]
 [-IncludeSeries <bool>] [-IncludeEpisodeFile <bool>] [-IncludeEpisodeImages <bool>]
```

## DESCRIPTION

This function retrieves calendar records.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-StarrCalendar
```

### EXAMPLE 2

```powershell
Get-StarrCalendar -InstanceName 'Main'
```

### EXAMPLE 3

```powershell
'
```
