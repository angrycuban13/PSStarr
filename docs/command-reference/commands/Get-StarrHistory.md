# Get-StarrHistory

## SYNOPSIS

Retrieves history from a Starr instance.

## SYNTAX

### Named (Default)

```
Get-StarrHistory [-InstanceName <string>] [-Application <string>] [-Since <datetime>]
 [-MovieId <int>] [-SeriesId <int>] [-SeasonNumber <int>] [-Page <int>] [-PageSize <int>]
 [-SortKey <string>] [-SortDirection <string>] [-EventTypeId <int[]>] [-EventType <string>]
 [-DownloadId <string>] [-MovieIdFilter <int[]>] [-SeriesIdFilter <int[]>] [-EpisodeId <int>]
 [-LanguageIdFilter <int[]>] [-QualityIdFilter <int[]>] [-IncludeMovie <bool>]
 [-IncludeSeries <bool>] [-IncludeEpisode <bool>]
```

### Explicit

```
Get-StarrHistory -Url <string> -ApiKey <string> [-Application <string>] [-Since <datetime>]
 [-MovieId <int>] [-SeriesId <int>] [-SeasonNumber <int>] [-Page <int>] [-PageSize <int>]
 [-SortKey <string>] [-SortDirection <string>] [-EventTypeId <int[]>] [-EventType <string>]
 [-DownloadId <string>] [-MovieIdFilter <int[]>] [-SeriesIdFilter <int[]>] [-EpisodeId <int>]
 [-LanguageIdFilter <int[]>] [-QualityIdFilter <int[]>] [-IncludeMovie <bool>]
 [-IncludeSeries <bool>] [-IncludeEpisode <bool>]
```

## DESCRIPTION

This function retrieves paged history or history for a specified date, Radarr movie, or Sonarr series.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-StarrHistory
```

### EXAMPLE 2

```powershell
Get-StarrHistory -InstanceName 'RadarrMain' -MovieId 42 -EventType grabbed
```

### EXAMPLE 3

```powershell
Get-StarrHistory -InstanceName 'SonarrMain' -SeriesId 7 -SeasonNumber 2
```
